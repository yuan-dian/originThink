originThink
===============

> 运行环境要求PHP7.1+，兼容PHP8.0。

## 安装

~~~
    Composer install 或 Composer update
~~~

## 文档

[完全开发手册](https://www.kancloud.cn/manual/thinkphp6_0/content)

## 核心内容
+ 采用ThinkPHP6.0框架
+ 前端采用layui构建
+ 用户管理
+ 配置管理
+ 菜单管理
+ 缓存管理
+ 权限管理
